# MTA Agentic Migration Prototype

This is a static, fully mocked build of the Konveyor MTA Agentic Migration UI.

## Development

```bash
npm install
npm run build
```

The production build uses `MOCK=full` and emits the static site to
`client/dist`. The GitHub Pages deployment serves it at
`/AppDev-UX-Prototypes/mta-agentic-migration/`.
